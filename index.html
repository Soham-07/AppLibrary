New here? Set up your free Hangar in 5 steps
  1. Create a free account at github.com.
  2. Create a new repository. Make it Public, name it anything — e.g. hangar.
  3. Upload this file into that repo, and rename it to index.html.
  4. In the repo, open Settings → Pages. Under "Branch," pick main and / (root), then Save. GitHub gives you a live link — that's your Hangar.
  5. Go to github.com/settings/tokens → generate a new fine-grained token, give it access to only this one repo with Contents: Read and write permission. Paste that token below, along with your username and repo name.

Kept only in this browser, on this device — never written into the site's files. This token, not the panel toggle above, is the real lock on your Hangar. Don't leave it saved on a public or shared computer.
