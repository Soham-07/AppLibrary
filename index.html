Connection

Your GitHub repo is the source of truth. Everything here lives in it.

First time? Set up your free hangar in 5 steps
  1. Create a free account at github.com.
  2. Create a new repository. Make it Public, name it anything — e.g. hangar.
  3. Upload this file into that repo, rename it to index.html.
  4. In the repo, open Settings → Pages. Branch: main, folder / (root). Save. Your live URL appears above.
  5. Visit github.com/settings/tokens → generate a fine-grained token → give it access to only this repo, with Contents: Read & write. Paste below.

Token stays in this browser only. It's never written into the site's files — it's your real lock on the repo.
